> **This skill is installed for the `{{flavor}}` (staging) flavor.** Every command and installer below already names `{{flavor}}` and `https://api.{{flavor}}.com`, so run them as written. Two things are deliberately left alone: the `--booking-types` enum value `wego`, which is unrelated to the flavor, and any mention of "production" or `wego.com` describing how the product behaves, which is true of both environments.
>
> **Nothing here is a production quote.** Every price, fare, room and availability figure comes from Wego's staging stack, so it can differ from what production would return and it is not something the user can act on. Give the figure when they ask, then say plainly that it is staging. Never present one as what a trip costs, never compare it against a production price, and never suggest booking on it. A `booking-link` here opens a staging checkout, not a real one. When the user wanted a real answer, they wanted the production `wego` skill.
