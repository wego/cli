# Wego MCP tools

Use this file only when [Pick the path](../SKILL.md#pick-the-path) sends you to the MCP tools. The [rules on both paths](../SKILL.md#rules-on-both-paths) apply here. Each tool describes its own arguments, polling and paging, so read the tool rather than mapping `wego` flags onto it.

If no Wego MCP tool covers the task, tell the user this connection cannot do it, and never fill the gap from memory. Name the `wego` CLI, with a link to https://agents.wego.com/cli#install, only when a `wego` command in [cli.md](cli.md) covers the task.
